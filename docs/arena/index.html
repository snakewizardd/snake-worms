HOW IT WORKS

The game is the referee. Models never touch the game state. Every move goes through the same virtual controller the built-in CPU uses: select weapon, face, aim, charge, fire.
Only game tools. Each model ran in its own locked-down GitHub Copilot SDK session that could only see SNAKES tools: get_state, aim_guide, move, jump, attack, skip_turn and taunt. No shell, no files, no web.
Real Player Mode. No solver and no damage preview. The aim guide shows the first 80 ticks of the arc and stops at terrain. Long shots need maths or judgement, so Fable computed its own ballistics.
Everything is logged. Every prompt, tool call, aim check, reasoning summary, decision, landing point and token is in the log. The video is the broadcast canvas recorded live.
