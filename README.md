## The world

Somewhere at the end of a long summer evening, on a little island floating in a warm sea, two families of snakes have decided they cannot share it.

They have bazookas. They have grenades. They have a sheep, and when the sheep is not enough, they have a sky full of sheep. They take turns. They say rude things to each other. They get blasted off cliffs, tumble across the island, bounce off rocks, and land in the ocean with a small, dignified *splash*. Somebody always lays a shed skin where they fell.

It's the kind of game you used to pass a controller around the couch for, with every shot a little show for the room. This one remembers that feeling, and builds it again from scratch.

## Play your way

**🧠 Vs CPU**: four brains to fight.

| Brain | What it's like |
|---|---|
| **Easy** | Forgets about the wind. Panics. Means well. |
| **Normal** | A solid shot who reads the wind and picks the right tool. |
| **Hard** | Simulates thousands of real shots before every turn. Knows exactly where you'll land. |
| **Troll** | Maximum disrespect. Skips turns to *"let you cook."* Builds a girder box over your head. Teleports next to you to say *"HI :)"*. Prefers the sheep. |

**🛋️ Hotseat**: two players, one keyboard or one controller, passed around the couch.

**🍿 CPU vs CPU**: put on a world, pick two brains, and watch them argue. Hold **Space** to fast-forward.

Name your team, choose how many snakes, turn time, starting health, crates, hazards, sudden death and the aim guide. The game remembers your setup next time.

## The vibe

The snakes talk. *"SKILL ISSUE." "WIND NERF WHEN." "TELL MY EGGS I LOVE THEM."* Land a kill and a pair of pixel sunglasses descends onto your snake. Drown someone and a single **F** rises from the waves. Get a double kill and an airhorn goes off. The killing blow plays in slow motion.

Every sprite, sound, voice and song in the game is generated by code as you play. There isn't a single image or audio file in it.

## 🤖 Live Clanker Arena: two frontier AIs, one island

<div align="center">

[![Claude Fable 5.1 vs GPT-6 Astra, playing SNAKES live](docs/arena/fable-5.1-vs-gpt-6-astra/poster.jpg)](https://snakewizardd.github.io/snake-worms/arena/)

**[▶ WATCH: CLAUDE FABLE 5.1 vs GPT-6 ASTRA](https://snakewizardd.github.io/snake-worms/arena/)** · [turn-by-turn report](docs/arena/fable-5.1-vs-gpt-6-astra/report.md) · [full decision log](docs/arena/fable-5.1-vs-gpt-6-astra/match.jsonl)

</div>

Two frontier models each took a team of snakes and played a real match, live, against each other.

They played it like **real players**. Neither got auto-aim. Each one saw the map, the positions and the wind, could check the same dotted aiming arc a human sees, knew the game's physics rules, and picked every angle and power itself. After each shot it was told where the shot actually landed, so it could correct.

Claude Fable 5.1 worked the ballistics out in its head, extrapolating past the end of the aim guide, and lobbed a bazooka over a hill to land **3 px** from its target. It dropped a piano on GPT-6 Astra (*"Requiem in D(oomer) minor"*). GPT-6 Astra hit back with venom, a sheep and a tail whip (*"One HP. Zero runway."*). Fable ended it with sheep rain straight down a shaft: *"Counting sheep? They're counting YOU."* 🏆

Every prompt, aim check, reasoning summary, decision, landing point and token is in the log. The video is the live broadcast, recorded as it happened.

**Think you can beat them?** In the arena, pick **YOU** for one seat and any frontier model for the other: same island, same aim guide, same rules, all of it recorded.

## Share it

The whole game is **one 169 KB file**: [`docs/index.html`](docs/index.html).
Download it, double-click it, and it plays offline. Send it to a friend, drop it on a USB stick, or upload it anywhere that hosts a web page.

---

<details>
<summary><b>For tinkerers</b></summary>

<br>

Built with TypeScript and Vite, with no runtime dependencies. You need [Node.js](https://nodejs.org) 20+.

```bash
npm ci              # install the exact dependency versions
npm run dev         # play locally with instant reload while you edit
npm test            # fires all 24 weapons + plays full CPU-vs-CPU matches headlessly
npm run export      # builds the single-file game into dist/snakes.html
```

**Run your own Live Clanker Arena** (needs the GitHub Copilot CLI, signed in):

```bash
npm run arena       # then open http://127.0.0.1:5173 → LIVE CLANKER ARENA
npm run test:arena  # free: full arena matches with mock players, no model calls
```

Pick **YOU** for a seat to play a frontier model yourself (keyboard + mouse, with the same aim guide the model gets), or pick two models to watch them fight. Free mock players are built in too. Choose **Real Player** (aim guide + physics) or **Full Oracle** (the engine's shot solver), and set a hard **AI-credit budget cap**. Each match saves a 1080p broadcast video, a turn-by-turn `report.md` and a complete `match.jsonl` to `arena-logs/`. Models run in locked-down sessions that can only see the SNAKES game tools. To make a highlight cut that fast-forwards the thinking: `node scripts/highlights.mjs arena-logs/<match>`.

Want to change how the game feels? Start here:

| File | What lives there |
|---|---|
| `src/config.ts` | Gravity, jump height, fall damage, aim speed |
| `src/themes.ts` | The three worlds: colors, teams, snake names, outfits, banter, music |
| `src/weapons.ts` | Every weapon's name, ammo, unlock round and description |
| `src/banter.ts` | Everything the snakes say |
| `src/ai.ts` | The CPU brains |
| `src/arena/` | Live Clanker Arena: tools, observations, controller, broadcast, recorder |
| `arena-host/` | Model adapters (Copilot SDK + free mocks), match logs, reports, video |

</details>
